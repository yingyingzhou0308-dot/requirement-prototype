# APP/H5 示例需求：用户选择附近服务网点并提交预约

## 终端类型

移动端 H5。用户从消息链接进入，无需在本案例中实现真实登录、定位 SDK 或服务端接口。

## 业务背景

用户需要为一项待办理的业务选择服务方式和附近服务网点，并提交预约。当前需要通过移动端页面让用户快速完成选择，减少电话或人工确认。

## 业务目标

- 用户可以从消息链接进入并看到待办理业务摘要。
- 用户可以选择服务方式、搜索服务网点并查看网点信息。
- 用户选择一个网点后可以提交预约，成功后看到预约结果和下一步说明。
- 定位失败、列表为空和提交失败时，用户能理解原因并继续操作。

## 目标用户

普通业务用户，使用手机浏览器完成一次服务网点预约。

## 页面入口和前置条件

- 用户从消息链接进入 H5。
- 消息链接携带业务对象标识；本原型使用模拟业务对象摘要。
- 默认服务方式为“到店办理”，默认不选中服务网点。
- 定位能力使用模拟状态，真实定位权限不在本案例范围内。

## 页面清单

### 页面一：预约信息页

- 展示业务对象摘要。
- 选择服务方式：到店办理、上门服务。
- 到店办理时展示当前位置、搜索框和服务网点列表。
- 上门服务时展示上门服务说明。
- 底部固定“确认预约”按钮，未选择网点时禁用。

### 页面二：预约成功页

- 展示成功状态、预约编号、服务网点、地址、营业时间和下一步说明。
- 提供完成按钮返回预约信息页。

## 核心流程

```text
消息链接
→ 查看业务对象摘要
→ 选择服务方式
→ 定位附近服务网点
→ 搜索服务网点
→ 选择一个网点
→ 查看地址、营业时间和距离
→ 点击确认预约
→ 提交处理中
→ 预约成功页
→ 完成或返回
```

## 业务规则

- 服务方式为“到店办理”时，必须选择一个服务网点后才允许确认预约。
- 服务方式为“上门服务”时，不需要选择服务网点，确认按钮可用。
- 服务网点列表一次只允许选中一个网点。
- 搜索按网点名称和地区关键字过滤；清空搜索后恢复完整列表。
- 定位失败时保留已选服务方式，允许重新定位或改为手动搜索。
- 列表为空或搜索无结果时不能确认预约，应提供清晰空态。
- 提交失败时保留服务方式、搜索内容和已选网点，允许重新提交。
- 提交过程中按钮进入加载状态，不允许重复点击。

## 状态范围

- 初始状态：到店办理、未选网点、确认按钮禁用。
- 已选择状态：显示选中网点摘要，确认按钮启用。
- 加载状态：模拟提交中，按钮显示加载文案。
- 空状态：无可用服务网点或搜索无结果。
- 异常状态：模拟定位失败或提交失败。
- 成功状态：展示预约编号和下一步操作。

## 系统能力和原型边界

- 定位、地图跳转和接口请求均为原型模拟，不调用真实 SDK 或接口。
- 不实现真实推送、短信、系统权限弹窗和支付能力。
- 右侧说明面板与手机内当前页面/状态同步。

## 待确认事项

- 服务方式、预约有效期和取消规则是否需要增加更多业务状态。
- 服务网点数据来源、排序口径和距离计算方式。
- 提交预约是否需要登录、验证码或二次确认。
