# 示例预期交付

使用本 Skill 处理“PUDO网点服务商配置”后，最终至少交付以下内容。

## 1. 简要需求理解

业务人员在后台配置服务商与一个或多个 PUDO 网点的关联关系，供订单转自提时判断网点是否支持服务商。核心约束是：同一网点不能重复配置同一服务商，多选网点在列表中保持同一条配置记录。

## 2. 页面清单

| 页面 | 目标 | 关键操作 |
| --- | --- | --- |
| 配置列表 | 查询和维护已有配置 | 查询、重置、新增、编辑、启用、停用、查看、分页 |
| 新增配置 | 创建服务商与多个网点的关联 | 选择服务商、选择网点、设置状态、填写备注、保存、取消 |

## 3. 合理假设

- 使用角色默认为“业务配置人员”。
- 服务商和网点选项使用模拟数据展示。
- 配置状态只包含“启用”和“停用”。
- 列表每页展示 5 条数据，用于演示分页。
- “启用”和“停用”属于即时状态切换，原型通过提示和列表刷新反馈结果。

## 4. 待确认事项

- 服务商和网点的真实数据来源及搜索方式。
- 是否需要按组织、区域或用户做数据权限隔离。
- 启用、停用是否需要二次确认或审批。
- 重复配置冲突时，是否需要提示已有配置的创建人和时间。
- 编辑时是否允许更换服务商，或只允许调整网点和状态。

## 5. 单文件 HTML 原型

应提供一个可直接双击打开的 HTML 文件，满足：

- 左侧约 65% 为后台原型，右侧约 35% 为需求说明。
- 左侧包含配置列表和新增配置页面。
- 点击“新增”进入新增页；点击“返回”或“取消”返回列表。
- 保存前检查服务商和网点必填。
- 选择已存在的服务商与网点组合时提示重复，并保留填写内容。
- 保存成功返回列表并显示提示。
- 多个网点在一条列表记录中合并展示。
- 页面切换时右侧说明同步变化。

## 6. 原型自检结果

交付前应确认字段、状态、按钮、权限、异常和验收标准已在原型与右侧说明中保持一致，并运行 `validate_html.py`。如果浏览器打开时出现报错、遮挡、错位或横向溢出，应先修复再交付。
