# APP/H5 示例预期输出

## 1. 需求分析

应输出业务背景、业务目标、目标用户、使用场景、终端类型、页面入口、页面清单、跳转关系、核心流程、字段、交互规则、状态、系统能力、合理假设、待确认事项和验收标准。

## 2. 页面清单

- 预约信息页：业务对象摘要、方式选择、定位、搜索、服务网点列表和底部确认按钮。
- 预约成功页：成功结果、预约编号、服务网点信息、下一步说明和完成按钮。

## 3. 页面流程

```text
消息链接 → 预约信息页 → 方式选择/网点选择 → 确认预约 → 加载 → 成功页 → 完成返回
```

异常分支包括定位失败、列表为空、搜索无结果和提交失败，提交失败必须保留用户选择。

## 4. HTML 原型

- 单文件 HTML，可直接双击打开。
- 左侧约 65% 为手机设备外壳中的交互原型。
- 右侧约 35% 为与当前页面/状态同步的需求说明卡片。
- 使用原生 HTML、CSS 和 JavaScript，不依赖 CDN、Node.js 或真实系统能力。

## 5. 预览和编辑能力

- 状态预览：初始、已选择、加载、空态、异常和成功。
- 选择方式、搜索列表、选择网点、提交、成功返回和 Toast 可交互。
- 使用 `data-k`、`contenteditable` 和 localStorage 编辑文案。
- 支持导出 HTML、恢复默认，导出文件仍可独立运行。

## 6. 自检结果

- 手机外壳比例正常，状态栏/顶栏固定，内容区独立滚动。
- 底部操作栏不遮挡最后一条内容，禁用与加载状态清晰。
- 空态、异常态、成功页和 Toast 限制在手机屏幕内。
- 右侧说明随当前页面/状态同步，字段、按钮和跳转规则与原型一致。
- HTML 校验通过，未发现外部 CDN 或明显 JavaScript 语法错误。
